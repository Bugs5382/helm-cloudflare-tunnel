# helm-cloudflare-tunnel 🐹

> 🧭 Helm chart that runs a Cloudflare Tunnel (cloudflared) for a Kubernetes workload.

## 📦 Install

```bash
go get github.com/Bugs5382/helm-cloudflare-tunnel
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check MIT headers (golic)
```
